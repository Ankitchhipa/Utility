# Utilify - All Tools & Utilities 🚀

Utilify is an all-in-one utility app designed to simplify your daily tasks.  
No need to install multiple apps — everything you need is available in one place.

---

## ✨ Features

### 📷 Scanner
- Scan documents instantly
- Convert images to PDF
- Auto edge detection

### 📄 PDF Editor
- Merge & split PDF files
- Edit and manage documents
- Add signatures

### 📝 Document Creator
- Create notes and documents easily
- Organize files efficiently

### 🧹 Junk Cleaner
- Remove unwanted files
- Free up storage space

### 🔍 Duplicate Finder
- Detect duplicate images and files
- Clean storage quickly

### 📱 App Backup
- Backup and restore apps safely

### 🧼 Social Media Cleaner
- Clean cache from social apps
- Improve performance

---

## ⚡ Why Choose Utilify?

- Saves storage and time
